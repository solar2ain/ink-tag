# InkTag firmware

[中文](README.md) | English

This preview contains only the CLI, WebUI, and documentation. It ships no flashable firmware; this directory is a placeholder for a later firmware release.

Firmware binaries are never committed to Git history. They are attached only to the matching GitHub Release.Treat the `artifacts` arrays in `manifest.json` as authoritative; an empty array means that this release provides no downloadable firmware.
