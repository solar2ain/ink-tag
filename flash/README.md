# 首次烧录入口

Windows 候选入口位于 `windows/`，下载版也包含在 `InkTag-flash-tools-v0.2.0.zip`。`runtime/` 只供这些入口调用，不是用户接口。Linux/macOS 首刷尚未完成本次实机资格测试，因此不提供会造成“已支持”误解的入口。

发布仓库不默认打包厂商 SDK 或专有烧录软件。每个公开脚本必须：

- 支持 `-Help`/`-h`，POSIX 脚本支持 `--help`；
- 在安全的平台上默认等待目标连接；
- 按完整主板 ID 选固件，不能只按 MCU 系列；
- 显示擦除、写入和校验进度，未连接时不刷屏；
- 烧录前核对 Release 中记录的 SHA-256；
- 需要外部软件时链接官方地址并写明实测版本；
- 保留该主板的原厂备份和 Flash 布局安全门禁。

具体命令、依赖和恢复判定见[完整烧录说明](../docs/zh-CN/flashing.md)。如果候选包附带了某个主板的 Full 固件，却没有可以脱离私有源码仓库运行的对应脚本，应报告为审核阻断项，不能临时用未经审核的厂商 GUI 步骤代替。
