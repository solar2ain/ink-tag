# Public-release legal gate

This private preview intentionally has no final public license yet.

Before changing repository visibility to public:

1. Audit every distributed firmware binary and the Web UI for upstream and vendor-license obligations.
2. Confirm whether any derivative of GPL-licensed upstream code remains; a rewrite or refactor alone does not remove those obligations.
3. Complete `THIRD_PARTY_NOTICES.md` and add the selected license or binary-use terms.
4. Confirm that vendor tools, SDK files, device packs, fonts, holiday data, and factory firmware are not redistributed without permission.
5. Run the exact release-candidate hardware and OTA regression plan.
