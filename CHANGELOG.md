# Changelog

All notable user-visible changes are recorded here. InkTag uses semantic versioning across firmware, OTA packages, Web UI, and release documentation.

## 0.2.0-preview.1

- Publish the protocol-0.2 CLI and WebUI for private prerelease testing.
- Include Full and OTA candidate artifacts for boards selected by the 0.2 release
  matrix. Beta and experimental status remains visible per exact board.
- Keep deferred Nordic and Dialog targets as documentation-only entries; no 0.2
  firmware for those boards is included in this candidate.
- Add bilingual WebUI, flashing, OTA and CLI manuals and deploy their rendered
  HTML pages beside the WebUI.
