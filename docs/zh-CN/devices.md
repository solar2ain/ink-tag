# 设备与屏幕说明

安装前请核对主控、主板丝印和屏幕。产品型号、主板标记和可下载范围见[已适配设备](supported-devices.md)，实测结果与局刷支持见[已实测屏幕](tested-screens.md)；本页帮助你选择屏幕配置、了解图片容量和换屏限制。

## 选择主板与安装包

- 先核对[设备表](supported-devices.md)中的主控和主板丝印，再选择对应安装包。同一产品型号可能有不同硬件版本。
- 带 NFC 与不带 NFC 的主板可能印着相同丝印，请选择与实际装配对应的配置。
- 完整烧录还会写入启动、恢复程序及屏幕、引脚等初始配置。不同主板即使共用 OTA 应用，也不能直接互换完整烧录包。
- 换过屏幕的设备，还需要核对屏幕控制器、颜色、分辨率和接线。

## 图片存储

下表按 **250×128（也适用于 128×250）、400×300 和 3.98 寸 768×552 图片，以每像素 2 位（2bpp）估算**。E6 使用两个 2bpp 阶段，合计按 **4bpp** 计算，并分别列出 720×480、760×568 两种较大分辨率。

保存图片会占用完整解码画面，加上 96 字节记录头，再按 4 KiB 对齐。各尺寸单张图片约占：

| 图片尺寸 | 颜色数据 | 单张占用（含记录头与对齐） |
| --- | --- | ---: |
| 250×128／128×250 | 2bpp | 8 KiB |
| 400×300 | 2bpp | 32 KiB |
| 3.98 寸 768×552 | 2bpp | 104 KiB |
| E6 3.7 寸 720×480 | 4bpp | 172 KiB |
| E6 3.64 寸 760×568 | 4bpp | 212 KiB |

以下张数是**按存储空间计算的容量，尚未套用 Free 版本的数量额度**。支持 Pro 的主控，Free 通常在可视区长边小于 300 像素时最多保存 10 张，其余最多 4 张。**DA14585 和 nRF52811 因固件尺寸限制仅提供 Free，无法激活 Pro，但不限制图槽数量，不套用上述 10／4 张额度**；能存多少张只取决于实际容量。E6 屏幕控制需要 Pro，这两个主控不支持。

1 KiB = 1,024 字节。`0` 表示单张图片放不下、无法保存图槽；`—` 表示不支持 E6。此表用于比较容量，不表示每块主板均可使用表中的全部屏幕，换屏请参阅[已实测屏幕](tested-screens.md)。

有多个图片区时，各区分别计算可容纳张数，单张图片不能跨区保存。目前最多使用 255 个图片 ID，因此 ZKC42B 的 250×128 容量估算列为 255 张，即使仍有剩余空间。

表中的空间仅用于图片，不是整颗 Flash 容量，也不是 App／OTA 空间。同主控不同主板、固件配置，以及外置 Flash 是否可用，都会影响结果，请以连接设备后的容量显示为准。估算假定所存图片均为该尺寸；实际按行对齐、方向与颜色格式不同，张数可能变化。RLE 可减少传输量，但图片保存后仍占完整帧空间；JPEG／PNG 文件大小不决定图槽占用。

部分大屏可以直接显示，但无法保存图槽或自主轮播。更换屏幕配置前，请先下载需要保留的图片，再按提示清理不兼容图片并重新上传。

## 温度与可用功能

屏温来自屏幕控制器，主控温度来自 MCU，二者不是同一读数。没有有效采样、采样已过期、设备忙或控制器不支持时显示 `--`，不是 0 °C。nRF52811 的 A0/A1 屏温尚未实测；DA 的屏温可用性同样随控制器和采样状态变化。

nRF52811 与 DA14585 为永久 Free，不提供 Pro 激活、Find、设备密码、NFC 动作或蓝牙改名。其他系列的 NFC、灯、按键和蜂鸣器取决于实际装配与设备返回的能力；没有硬件时不能靠测试按钮添加。设备备注与蓝牙广播名分开，默认备注是 `InkTag XXXX`，备注仅使用可打印英文字符。
