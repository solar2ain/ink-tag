# 设备与屏幕说明

请先识别准确 MCU 和 PCB，再选择完整烧录固件。以下是硬件与屏幕说明；本版本是否提供可安装文件、烧录入口是否可用，请查看[设备支持表](supported-devices.md)。屏幕功能实测不等于整机已经完成全部发布测试。

## 原屏与控制器

颜色缩写：BW 为黑白，BWR 为黑白红，BWRY 为黑白红黄，KWRYGB 为黑白红黄绿蓝。控制器型号之外，还需匹配 recipe（驱动配方）、原生分辨率、可视区和方向。

| GR5331 / OM ZKC21V 原屏 | SSD1680，适配 zkc21v | 128×250；可视 122×250 | 三色；不是盒马 SSD1619 同尺寸配置 |
| GR5513 ZKC42V 原屏 | UC8276，适配 zkc42v | 400×300 | 三色；与 SSD1683 配方不同 |
| GR5513/5515 ZKC42VM 原屏 | SSD1683，适配 zkc42vm | 400×300 | 三色；不能仅按 4.2 寸选择另一驱动 |
| OM ZKC21B 原屏 | JD79661，适配 zkc21b | 128×250；可视 122×250 | 四色 |
| OM ZKC42B 原屏 | JD79668AA，适配 zkc42b | 400×300 | 四色；与 Nebular 的 recipe 不同 |
| Hanshow Nowa 154R 原屏 | SSD1675，适配 nowa154r | 152×152 | 三色；原厂安装方向需保留 |
| Hanshow Nebular 213R 原屏 | JD79676，适配 nebular213r | 128×250；可视 122×250 | 四色；不能选成三色 |

## 已测屏幕的差异

| 主板 | 已有实际屏幕操作范围 | 不应扩大为 |
| --- | --- | --- |
| GR5331 ZKC21V | 原屏清屏、日历和图片，方向及黑红显示 | 任意 128×250 屏均可互换 |
| GR5513 ZKC42V | 原屏清屏/日历；华为 A0/A1 换屏的页面与图片操作 | GR5515 对全部换装屏的同等覆盖 |
| GR5515 ZKC42VM | 原屏；部分 Nebular/Huawei 换装屏有清屏结果 | 换装屏全部页面、颜色与连续刷屏均通过 |
| nRF52832 PriceETag | SSD1675 152×152 黑白屏的页面与传图 | 200×200 屏已完成相同测试 |
| nRF52811 EL022H2 | 盒马 2.13 三色：页面、图片、方向、屏温；华为 A0：页面/图片/方向/颜色；A1：图片/方向/颜色/轮播 | EL029H2、400×300 候选或 A0/A1 屏温已经实测 |
| DA14585 AESL42 | SES 2.13 UC8151 104×212 三色换屏：页面、图片、图槽与轮播 | 同时证明所有 SES 型号或温度回读 |

同一分辨率的两种控制器可能有不同电压、刷新波形、BUSY 极性和传输格式。请选择具体 IC 与适配项；自定义高级参数不是未知屏幕的自动识别工具。

## 图片存储

图片容量按完整帧、记录头和 Flash 扇区对齐计算，而不是 JPEG/PNG 的文件大小。RLE 可以减少传输量，但图片保存后仍占完整帧空间，不会增加图槽数量。实际容量、空闲 ID 和兼容性以设备报告为准。

| 配置 | nRF52811 图片区 472 KiB | DA14585 图片区 68 KiB |
| --- | --- | --- |
| 128×250 BWR | 每槽 8 KiB，约 59 张 | 每槽 8 KiB，约 8 张 |
| 128×296 BWR | 按设备实际配置计算 | 每槽 12 KiB，约 5 张 |
| 400×300 BWR / BWRY | 每槽 32 KiB，约 14 张；是容量参考，不是已测屏型声明 | 每槽 32 KiB，约 2 张 |
| Huawei A0/A1 768×552 BWRY | 每槽 104 KiB，约 4 张；A0/A1 已有换屏测试 | 单帧超过图片区；不可保存图槽或自主轮播 |

DA 大屏可使用相应直接传图路径，但不能将图片区扩大为固件运行内存。其他 MCU 的图片区随 PCB、实际 Flash 与布局不同，不沿用此表。更换分辨率或颜色配置可能使旧图片不兼容，应先下载保留，再按提示清理并重新上传。

## 温度与可用功能

屏温来自屏幕控制器，主控温度来自 MCU，二者不是同一读数。没有有效采样、采样已过期、设备忙或控制器不支持时显示 `--`，不是 0 °C。nRF52811 的 A0/A1 屏温尚未实测；DA 的屏温可用性同样随控制器和采样状态变化。

nRF52811 与 DA14585 为永久 Free，不提供 Pro 激活、Find、设备密码、NFC 动作或蓝牙改名。其他系列的 NFC、灯、按键和蜂鸣器取决于实际装配与设备返回的能力；没有硬件时不能靠测试按钮添加。设备备注与蓝牙广播名分开，默认备注是 `InkTag XXXX`，备注仅使用可打印英文字符。
