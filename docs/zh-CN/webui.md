# Web 上位机

电脑推荐 Chrome 或 Edge；iPhone／iPad 推荐 [Bluefy](https://apps.apple.com/app/id1492822055)；Android 首选 Chrome。不要在微信等内置窗口中连接设备，请在上述浏览器中打开网页并允许蓝牙访问。

扫描设备信息页二维码或打开带 `ble` 参数的设备链接时，WebUI 会尝试连接此网址已授权的同名设备。无法自动连接时会弹出连接对话框；点击“选择蓝牙设备”打开浏览器列表并确认目标。首次蓝牙授权需要用户点击，不能由网页静默代替。取消后不会反复连接，密码验证仍按设备设置执行。

InkTag Web 可使用在线 HTTPS 站点、编译后的静态包、离线 ZIP 或CLI 本地版。运行这些发布包不需要 Node.js。浏览器需要支持 Web Bluetooth；不支持时请使用[命令行工具](cli.md)。

## 安装与访问

在线版直接打开 [InkTag WebUI](https://solar2ain.github.io/ink-tag/)。本地版按以下方式安装：

安装 Python 3.11 或更新版本，从本仓库下载／拉取代码，或解压完整 CLI ZIP，进入同时包含 `cli/` 和 `webui/` 的根目录。推荐使用统一安装入口：

**Windows：**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_inktag.ps1
```

**macOS／Linux：**

```sh
sh install_inktag.sh
```

脚本会把 CLI 安装到 `cli/.venv`，并自动安装**本地 Find 查询服务的依赖**；Find 环境单独位于用户数据目录的 `find/runtime/.venv`。安装完成后以后台模式启动本地 WebUI 和 Find 查询服务（`webui start`）；关闭终端不会停止服务。安装完成时会显示可直接复制的启动、停止、状态和日志命令。macOS 新安装的数据和日志位于 `~/.inktag/`；已有旧目录时继续使用原目录，避免丢失会话或标签信息。不会修改系统 Python，也不会自动登录 Apple、连接设备或清除已有数据。

首次安装需要联网。Windows 还需预先安装完整版 7-Zip，首次会下载约 292 MB 的 Apple 认证组件镜像；macOS 使用系统原生认证组件，无需该镜像。Linux 的位置查询仍未完成资格验证。

只安装、不启动：Windows 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install_inktag.ps1 --prepare-only`；macOS／Linux 运行 `sh install_inktag.sh --prepare-only`。后续使用 `cli/inktag.ps1`／`cli/inktag.sh`，无需手动激活环境，例如：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\cli\inktag.ps1 --help
```

```sh
bash cli/inktag.sh --help
```

更新后重新运行统一安装脚本即可。只需要 CLI、不需要 Find 查询时，也可进入 `cli/`，运行原有的 `install.ps1` 或 `bash install.sh`。

本地地址默认是 `http://127.0.0.1:8787/`。默认数据目录：Windows `%LOCALAPPDATA%/InkTag`、macOS `~/.inktag/`（已有安装继续使用原目录）、Linux `$XDG_DATA_HOME/inktag`（未设置时为 `~/.local/share/inktag`）。不要将身份库或 Apple 会话放入公开目录。仅有静态 WebUI 或 standalone 不包含查询服务。

### 手机与局域网访问

本机使用无需额外登录。需要手机访问时，在CLI 本地版目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\cli\inktag.ps1 webui serve --repo . --lan
```

```sh
bash cli/inktag.sh webui serve --repo . --lan
```

已激活 Python 环境时，可运行 `inktag-cli webui serve --repo . --lan`。服务自动识别本机地址、生成 HTTPS 证书，并在启动窗口显示访问地址和本次访问密码；手机连接同一局域网，使用用户名 `inktag` 登录。只在手机上信任自己电脑生成的证书；证书必须受手机浏览器信任，蓝牙功能才可用。部分手机浏览器本身不支持 Web Bluetooth。

本机防火墙需允许选定端口。不要把带有私人数据或 Find 的服务直接暴露到互联网。自定义域名可加 `--allowed-host 域名`，已有证书使用 `--tls-cert` 和 `--tls-key`。高级部署可用 `--access-password-stdin` 从标准输入提供固定的服务访问密码；它与设备密码、Apple 密码无关。默认不需要这些高级参数。

## 连接设备

点击顶部“连接”，选择准确蓝牙名称，并等待身份和配置读取。连接历史的标题是蓝牙名，下方显示设备名称。名称相近不代表同一台设备。普通应用与 Recovery 是不同运行角色；需要时按提示再次授权。

首次打开会显示三页入门教程。“设置 → 客户端设置 → 关于”可重新打开教程，并提供项目和 Web 上位机地址。

## 页面与操作

“图片”用于导入、裁剪和配色；“创作”提供模板；“资源”管理内容。“设置”分为两组：设备设置含概览、显示、板卡、交互、激活、固件、日志和测试；客户端设置含偏好设置与关于。设备功能是否可操作由当前设备的支持情况决定，客户端设置无需连接设备。

### 第一张图片

1. 在“设置 → 设备设置 → 显示”核对当前屏幕预设、控制器、颜色和方向。
2. 进入“图片”导入照片，调整裁剪、旋转、亮度和配色；以设备预览为准。
3. 选择直接显示，或保存到可用图槽后显示。
4. 等待传输和物理刷新完成。屏幕闪烁通常属于刷新波形，传输到 100% 后仍可能需要等待。

“创作”提供日历、时钟、天气站、日期牌等模板，可在发送前预览。截图与操作箭头见首次打开的教程，或从“设置 → 客户端设置 → 关于”重新打开。

### 图槽、轮播和换屏

在资源列表查看实际可用 ID、显示、下载或删除图片。删除会留下空位，不能假定 ID 连续。保存两张兼容图片后可开启轮播，断开蓝牙后仍由设备按间隔播放；需要结束时使用停止。

不同屏幕的图槽容量见[设备说明](devices.md)。更换屏幕几何或颜色后可能需要清除不兼容图片，先下载要保留的内容。保存屏幕设置与清除图片是不同操作，必须阅读确认框。

先核对屏幕尺寸、颜色、控制器和方向，再发送内容。刷新中不要断电；需要更换操作时使用停止并等待确认。图片存储和轮播只在支持的设备上提供。更改屏幕配置可能使旧图片不兼容，请先阅读清理提示。

设备密码在设备操作中管理，可设置、修改或删除；修改和删除必须重新验证原密码。仅在主动勾选“记住密码”时保存设备控制凭据；它不会替代原密码验证。请仅在可信浏览器中使用此选项。

“设置 → 设备设置 → 激活”用于支持 Pro 的设备。防丢器（苹果 Find My 网络）、更多图槽、NFC 交互等能力的范围与激活步骤见 [Pro 说明](pro.md)。

## 画板与天气站

「创作」中的画板支持文字、图片框、表格、列表、二维码和笔迹。双击图片框选择图片，
可调整适配方式与抖动算法；「设备效果预览」在本机模拟目标色板，不连接或刷新设备。
静态页面可使用浏览器字体，不需要向设备安装字库。

天气模板使用独立的天气数值、图标、折线图和预报控件。编辑后导出主机任务，交给 CLI
绑定设备并定时运行；关闭浏览器不会停止 CLI。步骤见[主机动态页面与天气站](host-pages.md)。

## 浏览器偏好

打开“设置 → 客户端设置 → 偏好”，可以选择跟随浏览器、简体中文或英文，以及跟随系统、亮色或暗色主题。设置仅保存到当前网址的浏览器，不修改设备语言或固件。英文目前覆盖导航、偏好和教程，设备详情仍可能保留原文。

教程可从“设置 → 客户端设置 → 关于”重新打开。不同主机名/端口有各自的偏好，清除网站数据会恢复默认；浏览器禁止存储时仅本次打开有效。操作进度和等待提示始终保留。

## NFC 和扩展输入输出

| 项目 | 使用条件和作用 |
| --- | --- |
| 碰一碰连接（Free） | 配有可用 NFC 标签的设备可由手机读取已有上位机链接。首次蓝牙连接仍需浏览器授权；读取链接不执行设备动作。 |
| NFC 手机命令（Pro） | 切换页面与已支持的短指令需要 Pro、可用硬件及设备权限；NFC 传图尚未开放。 |
| 按键与蜂鸣器 | 未提供能力的扩展项标注“暂未实现”，不能写入设备。已有合格板载按键按实际能力提供，不受此标注影响。 |

## 更新与诊断

本地服务在数据目录的 `webui-build-cache/` 中保留最近使用过的编译资源 30 天，
避免更新后已打开的页面找不到旧模块。这里只缓存带哈希名称的静态文件，不缓存账号、
设备凭据或 Find 数据。图片工具加载失败时可以局部重试；若需刷新网页，请先结束设备操作。
“清除图片”只清空当前导入的图片，不刷新网页或删除设备图片。

“设置 → 设备设置 → 固件”执行 OTA。文件验证通过只表示包可用，OTA 成功还必须完成设备校验、返回应用和身份确认。错误或结果未知时先阅读提示，不要连续重发。

“设置 → 设备设置 → 日志”包含运行诊断。无有效值显示 `--`，不表示零；屏温与主控温度是不同来源。走时诊断是只读偏差观察，长期测试时应避免自动校时。详细步骤见[OTA 与 Recovery](ota.md)。

纯静态模式的图片处理和蓝牙通信在本机完成。Find 等外部服务会按相应功能说明访问网络；私有数据应单独备份，不随固件包分发。


## Find 查询与迁移

静态版可以首次登记并保存加密迁移资料，本地版可以导入或导出全部标签。操作见 [Find 查询与加密迁移](find.md)。

## NFC 使用说明

设备支持 NFC 时，“设置 → 交互”只展示使用说明，不需要选择模式、保存配置或关闭 NFC。

用手机读取标签可打开设备链接，首次蓝牙连接仍需浏览器授权。手机写命令需要 Pro 和对应固件支持：打开 NFC Tools，选择“写入 → 添加记录 → 文本”，填写设备支持的命令后贴近标签。例如 `NEXT` 显示下一张图片、`CALENDAR` 打开日历、`CLOCK` 打开时钟。界面只列出当前设备声明的命令；支持按名称显示时，也可填写已有图片的完整名称。

普通碰触不作为独立的切页模式。NFC 传图尚未开放。

## 离线版的资源

下载 `InkTag-WebUI-standalone-*.zip` 后完整解压，打开 `InkTag-WebUI.html` 即可。HTML、字体和教程图片已在同一个 ZIP 中；请保留旁边的 `assets` 文件夹，不必另下资源包。

若自行移走可选资源，相应书法字体和教程图片将不可用；设备连接、自己的图片处理和 OTA 不受影响。用到缺失字体的作品会提示补齐字体后再发送。
