# Web 上位机

扫描设备信息页二维码或打开带 `ble` 参数的设备链接时，WebUI 会尝试连接此网址已授权的同名设备。无法自动连接时会弹出连接对话框；点击“选择蓝牙设备”打开浏览器列表并确认目标。首次蓝牙授权需要用户点击，不能由网页静默代替。取消后不会反复连接，密码验证仍按设备设置执行。

InkTag Web 可使用在线 HTTPS 站点、编译后的静态包、独立 HTML 或本地服务包。运行这些发布包不需要 Node.js。浏览器需要支持 Web Bluetooth；不支持时请使用[命令行工具](cli.md)。

## 安装与访问

| 方式 | 使用方法 | 适用场景 |
| --- | --- | --- |
| 在线版 | 打开 [InkTag Web](https://solar2ain.github.io/ink-tag/) | 无需安装；需要网络加载网页 |
| 本地服务包 | 解压 `InkTag-local-server`，按下方命令启动 | 本机固定地址、持久化服务与可用的 Find 后端 |
| 静态 ZIP | 解压 `webui`，通过本机 HTTP 或可信 HTTPS 提供网页 | 自行托管；不含本地数据/Find 服务 |
| 独立 HTML | 使用下载的 `InkTag-WebUI-standalone-*.html` | 单文件使用；蓝牙可用性取决于浏览器安全上下文策略 |

推荐使用支持 Web Bluetooth 的 Chrome 或 Edge。不同系统、浏览器版本和企业策略可能限制蓝牙；没有蓝牙入口时改用 CLI，不要关闭浏览器安全检查。

本地服务需要 Python 3.11 或以上。进入解压后的 `InkTag-local-server`：

```powershell
# Windows
install.cmd
```

```sh
# macOS 运行 install.command；Linux：
sh install.sh
```

打开 `http://127.0.0.1:8787/`。退出终端会停止前台服务；再次启动仍读取同一用户的数据目录。Windows 默认使用 `%LOCALAPPDATA%/InkTag`。不要将本地身份库、苹果会话或私有凭据放进公开下载目录。

静态 ZIP 可以在 `webui` 目录运行 `python -m http.server 8787 --bind 127.0.0.1`，然后访问上述本机地址。它不提供 Find 后端。将服务器开放到局域网需配置可信 HTTPS；普通局域网 HTTP 不满足 Web Bluetooth 的安全要求。

### 手机与局域网访问

本机使用无需额外登录。需要手机访问时，在本地服务包目录运行：

```console
python start.py --lan
```

已安装 CLI 时可运行 `inktag webui serve --repo . --lan`。服务自动识别本机地址、生成 HTTPS 证书，并在启动窗口显示访问地址和本次访问密码；手机连接同一局域网，使用用户名 `inktag` 登录。只在手机上信任自己电脑生成的证书；证书必须受手机浏览器信任，蓝牙功能才可用。部分手机浏览器本身不支持 Web Bluetooth。

本机防火墙需允许选定端口。不要把带有私人数据或 Find 的服务直接暴露到互联网。自定义域名可加 `--allowed-host 域名`，已有证书使用 `--tls-cert` 和 `--tls-key`。高级部署可用 `--access-password-stdin` 从标准输入提供固定的服务访问密码；它与设备密码、Apple 密码无关。默认不需要这些高级参数。

## 连接设备

点击顶部“连接”，选择准确蓝牙名称，并等待身份和配置读取。连接历史的标题是蓝牙名，下方显示设备名称。名称相近不代表同一台设备。普通应用与 Recovery 是不同运行角色；需要时按提示再次授权。

首次打开会显示三页入门教程。“设置 → 客户端设置 → 关于”可重新打开教程，并提供项目和 Web 上位机地址。

## 页面与操作

“图片”用于导入、裁剪和配色；“创作”提供模板；“资源”管理内容。“设置”分为两组：设备设置含概览、显示、板卡、交互、激活、固件、日志和测试；客户端设置含偏好设置与关于。设备功能是否可操作由当前设备的支持情况决定，客户端设置无需连接设备。

### 第一张图片

1. 在“设置 → 设备设置 → 显示”核对当前屏幕预设、控制器、颜色和方向。
2. 进入“图片”导入照片，调整裁剪、旋转、亮度和配色；以设备预览为准。
3. 选择直接显示，或保存到可用图槽后显示。
4. 等待传输和物理刷新完成。屏幕闪烁通常属于刷新波形，传输到 100% 后仍可能需要等待。

“创作”提供日历、时钟、天气站、日期牌等模板，可在发送前预览。截图与操作箭头见首次打开的教程，或从“设置 → 客户端设置 → 关于”重新打开。

### 图槽、轮播和换屏

在资源列表查看实际可用 ID、显示、下载或删除图片。删除会留下空位，不能假定 ID 连续。保存两张兼容图片后可开启轮播，断开蓝牙后仍由设备按间隔播放；需要结束时使用停止。

不同屏幕的图槽容量见[设备说明](devices.md)。更换屏幕几何或颜色后可能需要清除不兼容图片，先下载要保留的内容。保存屏幕设置与清除图片是不同操作，必须阅读确认框。

先核对屏幕尺寸、颜色、控制器和方向，再发送内容。刷新中不要断电；需要更换操作时使用停止并等待确认。图片存储和轮播只在支持的设备上提供。更改屏幕配置可能使旧图片不兼容，请先阅读清理提示。

设备密码在设备操作中管理，可设置、修改或删除；修改和删除必须重新验证原密码。仅在主动勾选“记住密码”时保存设备控制凭据；它不会替代原密码验证。请仅在可信浏览器中使用此选项。

“设置 → 设备设置 → 激活”用于支持 Pro 的设备。防丢器（苹果 Find My 网络）、更多图槽、NFC 交互等能力的范围与激活步骤见 [Pro 说明](pro.md)。

## 画板与天气站

「创作」中的画板支持文字、图片框、表格、列表、二维码和笔迹。双击图片框选择图片，
可调整适配方式与抖动算法；「设备效果预览」在本机模拟目标色板，不连接或刷新设备。
静态页面可使用浏览器字体，不需要向设备安装字库。

天气模板使用独立的天气数值、图标、折线图和预报控件。编辑后导出主机任务，交给 CLI
绑定设备并定时运行；关闭浏览器不会停止 CLI。步骤见[主机动态页面与天气站](host-pages.md)。

## 浏览器偏好

打开“设置 → 客户端设置 → 偏好”，可以选择跟随浏览器、简体中文或英文，以及跟随系统、亮色或暗色主题。设置仅保存到当前网址的浏览器，不修改设备语言或固件。英文目前覆盖导航、偏好和教程，设备详情仍可能保留原文。

教程可从“设置 → 客户端设置 → 关于”重新打开。不同主机名/端口有各自的偏好，清除网站数据会恢复默认；浏览器禁止存储时仅本次打开有效。操作进度和等待提示始终保留。

## NFC 和扩展输入输出

| 项目 | 使用条件和作用 |
| --- | --- |
| 碰一碰连接（Free） | 配有可用 NFC 标签的设备可由手机读取已有上位机链接。首次蓝牙连接仍需浏览器授权；读取链接不执行设备动作。 |
| NFC 切换页面（Pro） | 切换页面与已支持的短指令需要 Pro、可用硬件及设备权限；NFC 传图尚未开放。 |
| 按键与蜂鸣器 | 未提供能力的扩展项标注“暂未实现”，不能写入设备。已有合格板载按键按实际能力提供，不受此标注影响。 |

## 更新与诊断

本地服务在数据目录的 `webui-build-cache/` 中保留最近使用过的编译资源 30 天，
避免更新后已打开的页面找不到旧模块。这里只缓存带哈希名称的静态文件，不缓存账号、
设备凭据或 Find 数据。图片工具加载失败时可以局部重试；若需刷新网页，请先结束设备操作。
“清除图片”只清空当前导入的图片，不刷新网页或删除设备图片。

“设置 → 设备设置 → 固件”执行 OTA。文件验证通过只表示包可用，OTA 成功还必须完成设备校验、返回应用和身份确认。错误或结果未知时先阅读提示，不要连续重发。

“设置 → 设备设置 → 日志”包含运行诊断。无有效值显示 `--`，不表示零；屏温与主控温度是不同来源。走时诊断是只读偏差观察，长期测试时应避免自动校时。详细步骤见[OTA 与 Recovery](ota.md)。

纯静态模式的图片处理和蓝牙通信在本机完成。Find 等外部服务会按相应功能说明访问网络；私有数据应单独备份，不随固件包分发。
