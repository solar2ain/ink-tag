# 客户端更新

中文 | [English](../en/updates.md)

在 WebUI 的“设置 → 客户端设置 → 关于”中查看当前版本并检查更新。WebUI、CLI 与设备固件的版本分别显示；更新客户端不会自动更新设备。

## 下载和安装

1. 检查新版本及更新说明，从项目 [GitHub Releases](https://github.com/solar2ain/ink-tag/releases) 下载所需附件。尚无附件时表示该版本暂不可下载。
2. 按[下载与校验](releases.md)检查文件，选择适合自己的客户端。
3. 在线 WebUI：重新打开页面即可获取已上线的版本。独立 HTML：下载新文件后打开；本地服务：停止旧服务，按 [WebUI 使用说明](webui.md)更新文件并重新启动，保留原数据目录。
4. CLI：按 [CLI 手册](cli.md)在原独立环境内更新，运行 `inktag --version` 确认版本。

本期不提供固件或有线烧录包，因此没有可安装的设备固件更新。以后有匹配的 OTA 包时，再按[无线升级](ota.md)操作；不要使用其他主控或板型的文件。校验和只检查文件完整性，不能代替固件签名验证。

## 检查失败怎么办

检查超时或网络不可用不会影响连接设备及普通操作。可稍后重试，或直接查看 Releases；网页站点不可用时使用本地版。未找到较新版本不代表所有设备均支持相同功能。

检查更新不上传设备地址、密码、身份或 Find 数据。安装后若遇到问题，保留本地数据和错误信息，不要通过删除数据目录或重刷设备来修复客户端更新。
