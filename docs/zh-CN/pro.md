# InkTag PRO 功能与激活

中文 | [English](../en/pro.md)

InkTag基础版（BASIC）提供图片、日历、时钟和设备维护，已能满足大部分日常使用需求。高级版（PRO）增加更多高级和实验功能。实际功能以设备能力为准。

## 功能对照

| 功能 | 基础版（BASIC） | 高级版（PRO） |
| --- | --- | --- |
| 图片、内置日历和时钟 | 支持 | 支持 |
| 非 E6 屏幕原生颜色、方向与普通全刷 | 支持 | 相同 |
| 高级屏幕控制 | 不提供 | 部分屏幕局刷与 E6 六色屏幕控制；需兼容硬件、接线和驱动，离线转换及预览不受限制 |
| 蓝牙连接、诊断、OTA 与 Recovery | 支持 | 支持 |
| 图片存储与轮播 | 以设备可用容量为准 | 相同 |
| 防丢器（苹果 Find My 网络） | 不提供 | 激活并配置后，可利用 Find My 网络查询设备位置 |
| NFC | — | 按硬件支持手机读取设备链接、写入指令或传图 |
| 设备密码 | 不提供 | 可设置设备密码；修改或关闭需重新验证原密码 |
| 设备备注 | 可修改 | 可修改 |
| 蓝牙广播名 | 保持出厂名称 | 可按设备规则修改 |
| 显示标识 | 固定显示 `InkTag` | 可调整或隐藏 `InkTag Pro` |
| 自定义动态设备布局（待开发） | — | 规划中，尚不可用；当前画板发送静态图片 |

> InkTag 基础版固件免费使用。若从商家购买设备或相关服务后遇到问题，请联系购买渠道。大部分高级版功能属于实验功能，请谨慎开通。

图槽数量取决于屏幕尺寸、颜色和实际存储容量。nRF52811 和 DA14585 只提供基础版（BASIC）。

## 防丢器与 NFC

| 功能 | 使用条件与限制 |
| --- | --- |
| 防丢器 | 利用苹果 Find My 网络，不是 GPS 实时定位；位置更新依赖附近参与网络的设备与网络状态。当前为实验功能，默认关闭，需要支持的固件、PRO 授权及单独的 Find 身份配置 |
| Find 查询 | 使用具备相应后端的客户端或本地服务；并非只打开静态网页就能查询。妥善保存本地私有数据，不公开身份密钥 |
| NFC 交互 | 主板需具有受支持的 NFC 硬件；通过手机命令按图片名称显示及清屏等设备动作均需 PRO。不同板型支持的指令可能不同 |
| NFC 连接 | 高级版可通过受支持的 NFC 标签打开设备链接；蓝牙连接仍需浏览器授权 |

## NFC 用法

在支持 NFC 的高级版标签上，可以用手机打开设备链接、写入命令或传图。**D3-Pro InkTag 版**在 InkTag QQ 群 **418446983** 获取。完整步骤见 [NFC 使用指南](nfc.md)。

## 在 Web 上位机中激活

1. 连接运行 InkTag 的设备，确认主控、板型和设备身份。
2. 打开“设置 → 设备设置 → 激活”，读取页面显示的当前设备码。若提示“该设备不支持激活”，不要使用其他型号的激活码。
3. 按正式领取流程取得与该设备匹配的激活码，在同一设备的页面输入并提交。已启用设备密码时，先按页面提示完成验证。
4. 等待设备确认，再读取激活状态。页面显示 PRO 后，防丢器和密码可按需单独设置，NFC 使用说明位于交互页面。

请妥善保存激活码，不公开截图、日志或二维码中的凭据。普通应用 OTA 保留激活状态；首次完整烧录或有线恢复前应另行保存重要数据。激活失败时查看提示与日志，确认设备和代码匹配，不使用绕过校验的操作。
