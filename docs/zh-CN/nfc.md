# 用 NFC 控制价签和传图

[English](../en/nfc.md)

先用 WebUI 连接价签，在设备的交互页面确认 NFC 能力，并确认设备已安装对应版型的高级版固件并激活 PRO。打开链接、写入文本命令和传图是不同能力，以当前主板和固件支持为准。

## 碰一碰打开设备页面

解锁手机，打开 NFC，把手机的 NFC 天线贴近价签。手机读到设备链接后，在支持 Web Bluetooth 的浏览器中打开，按提示选择标签并授权。首次连接需要手动确认。

## 写入文本命令

在 NFC Tools 等支持 NDEF 文本记录的工具中，选“写入 → 添加记录 → 文本”，每次填入一条命令，再点击写入并贴近价签。

| 示例 | 动作 |
| --- | --- |
| `日历` 或 `calendar` | 显示内置日历 |
| `时间` 或 `clock` | 显示内置时钟 |
| `设备` 或 `device` | 显示设备信息 |
| `slot-3` | 显示图槽 3，须已存有图片 |
| `日落` | 按名称显示已存图片。用 WebUI 给图槽图片命名后，直接写入该名称。需要固件支持按图片名称显示 |
| `time#<当前 UTC Unix 秒数>` | 在支持的固件上单独校时，保留设备时区和当前页面 |

按名称显示时，填写保存到设备的图片名称，无需加命令前缀。查看屏幕确认动作完成。NFC 写入提示表示手机已发出记录，屏幕刷新可能还在进行。校时时建议用 D3-Pro InkTag 版发送手机当前时间。

## 在 WebUI 中使用 NFC

### 写入命令

打开 **工作台 → 快捷控制 → NFC 控制**。页面会根据浏览器支持的接口显示入口。

- **安卓 Chrome**。打开手机 NFC，在 HTTPS 页面选择命令，按浏览器提示授权后，将手机贴近目标价签。写入时每次只贴一个价签。手机 NFC 传图请使用下节介绍的 D3-Pro InkTag 版。
- **桌面 Chrome 或 Edge**。在 HTTPS 或浏览器信任的本地页面中，把价签放在 PN532／PCR532 读卡器上，选择命令，然后按提示选择读卡器的串口。浏览器可能会复用之前授权的串口。

「日历」和「时钟」快捷按钮在写入时附上当前 UTC 时间和本地时区偏移，例如 `calendar#1795276800,+480`。旧固件可在「自定义」里发送 `calendar` 或 `clock`，保留设备已有的时间和时区。「时钟」会先提示频繁刷新可能增加耗电。也可以填图槽编号，或在「自定义」中输入固件支持的图片名称。

网页提示写入成功后，请查看价签屏幕确认命令执行。

### 用桌面读卡器传图

1. 在 **图片** 页选择图片，设置实际屏幕的尺寸、方向和颜色。
2. 把价签放在读卡器上，点击 **NFC 传图**，按提示选择串口。
3. WebUI 读取价签的屏幕参数，确认匹配后开始发送。传图完成后，等待墨水屏刷新。图片会直接显示在价签上。

进度以设备确认的数据为准。显示的速度只计传输阶段，使用压缩时按压缩后的数据大小计。中断或超时后，先查看价签状态，再决定是否重发。

## 用 Android 手机传图

1. 从 [高级版获取说明](pro.md#获取高级版固件)进入 **InkTag QQ 群 418446983**，在群公告获取 **D3-Pro InkTag 版**及与当前固件兼容的版本说明。
2. 打开应用，选择实际屏幕的尺寸和色彩模式，再选一张图片。预览裁切、方向和颜色。
3. 发起 NFC 传图，将手机天线贴在价签 NFC 区域，传输期间保持位置。如果应用提示尺寸或色彩不匹配，回到 WebUI 核对设备的屏幕配置。
4. 页面提示传输结束后，等待价签完成刷新。传输不稳定时，取下较厚或带金属的保护壳，重新对准 NFC 区域再试。

支持的板型见[已适配设备](supported-devices.md)。手边的手机或标签暂不支持 NFC 传图时，可用 [WebUI 图片页](webui.md) 走蓝牙传图。

## 传图速度参考

Type 2 和 Type 4 是 NFC Forum 定义的两种标签类型，规定手机或读卡器如何与价签通信。

- **NFC Forum Type 2 Tag（2 型标签）** 基于 NFC-A 技术读写标签。[NFC Forum Type 2 规范](https://nfc-forum.org/build/specifications/type-2-tag-specification/)
- **NFC Forum Type 4 Tag（4 型标签）** 使用 ISO 数据交换协议（ISO-DEP）与标签通信。[NFC Forum Type 4 规范](https://nfc-forum.org/build/specifications/type-4-tag-specification/)

汉朔 TLSR8359 标签多采用 Type 4，ZKONG 的 Goodix 与 OnMicro 标签多采用 Type 2。以下是不同价签和图片的实测样本。大小为压缩后的图片数据，时间从发送第一批图片数据到最后一批确认，另计读卡、初始化和墨水屏刷新。

| 实测设备 | PN532／PCR532 读卡器 | Android 手机（D3-Pro InkTag 版） |
| --- | --- | --- |
| 汉朔 TLSR8359，Type 4，4.2 寸 | 约 4.6 kB，**1.6 秒** | 约 7.4 kB，**2.5–2.8 秒** |
| 汉朔 Nebular-213R，Type 4，2.13 寸 | 约 4.6 kB，**3.9 秒** | 暂无同板型的实测计时 |
| ZKONG Goodix，Type 2，4.2 寸 | 约 4.6 kB，**8.9–9.0 秒** | 同一张约 4.6 kB 的图，**19.7–23.4 秒**。约 29.2 kB 的照片样本用了 **126 秒** |
| ZKONG OnMicro，Type 2，4.2 寸 | 约 2.2 kB，**5.0 秒** | 约 14.3 kB，**71.7 秒** |

**ZKONG Type 2 传图较慢，仅建议用于小屏上的高压缩率简单图片。其他场景建议改用蓝牙传图。**

同一尺寸的图片也可能差很多。内容越复杂、压缩后越大，贴卡时间通常越长。手机提示设备已接受刷新后，可以移开手机，等墨水屏更新完成。表中手机数据来自 Android。4.2 寸 Type 4 也有原版 iOS D3-Pro 的成功记录，未记录可比耗时。

## 用命令行操作 NFC 读卡器

仓库及完整 CLI 下载包包含 PN532／PCR532 NFC 工具。同一套命令可用于兼容的 Type 2 和 Type 4 高级版标签，也支持读取链接、写文本命令和校时。安装与命令示例见 [PN532／PCR532 工具说明](../../tools/nfc/README.md)。
