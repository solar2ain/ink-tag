# 无线更新与 Recovery

OTA 更新应用固件，通常保留设备配置和内容。首次安装、Recovery 本身更新或无法无线恢复时，请使用[完整烧录](flash.md)。不要修改 OTA 包或将完整烧录文件当作 OTA 上传。

## 更新步骤

1. 从发布包选择与准确主控和板型对应的 OTA 文件，并校验 SHA-256。
2. 稳定供电，连接设备，在“设置 → 设备设置 → 固件”中选择文件。
3. 等待文件验证、进入 Recovery、传输和设备校验完成。
4. 按提示重连普通应用，确认设备身份、实际运行镜像和版本。正常更新还会校时一次。

文件验证的勾选标志只表示包通过检查；传输到 100% 也不是最终成功。只有最终应用验证完成，才表示 OTA 完成。

## Recovery 的使用

Recovery 是设备的无线更新模式，通常显示对应身份的 `_OTA` 蓝牙名。CLI 和 WebUI 可在已安装 Recovery 提供相应能力时安全返回正常应用。旧 Recovery 或应用无效时可能只允许上传合格固件，不能强制退出。

CLI 入口为 `inktag --address ADDRESS recovery enter` 和 `recovery resume-app`；应用进入 Recovery 仍受设备密码验证控制。Recovery 校验固件签名、兼容性和完整性，不会以退出操作替代这些检查。

## 发生中断或错误

保留错误提示和文件摘要，确认设备目前处于应用还是 Recovery。不要重放结果未知的退出、复位或写入命令。应用未返回时，进度完成不能当作成功；按客户端提示恢复传输或使用对应完整烧录恢复路径。

蓝牙地址一致也不保证浏览器可直接复用缓存服务。角色切换时需要重新识别实际服务和身份；不要连接附近相似名称的另一台设备。
