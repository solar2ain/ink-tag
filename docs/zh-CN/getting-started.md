# 首次使用

本指南帮助您从首次安装到显示第一张图片。请选择与设备当前状态对应的步骤。

## 认识墨水屏

墨水屏呈现类似纸张的阅读观感，不靠背光持续发光，在合适照明下阅读较舒适。护眼是使用体验描述，不是医疗保证；仍需保持适合的照明、距离和休息。了解更多可查看 [Good Display 墨水屏问答](https://www.good-display.com/faq/1.html)。

墨水屏利用环境光显示内容，暗处需要外部照明。一次全刷通常需要几秒到十几秒，部分多色屏或低温环境会更久；刷新中的闪烁通常是正常过程，请保持供电并等待完成，不要连续重复操作。

刷新完成后，屏幕保持画面无需持续供电，断电后也能保图。不频繁刷新并保持低功耗待机时，纽扣电池也能长时间使用。不过蓝牙、主控和计时仍有耗电，实际续航取决于电池容量、刷新频率、温度和蓝牙、Find 等活动，不能将屏幕保图理解为整机零功耗。

Web 上位机首次打开会显示三页入门教程，配有实际界面的截图、编号框和箭头。点击截图可以放大，在“设置 → 客户端设置 → 关于”中可随时重新打开。

## 1 准备设备和客户端

准备稳定供电、支持 Web Bluetooth 的浏览器，或 Python 3.11 及以上版本的命令行环境。使用 HTTPS 或本机站点访问 Web 上位机，并允许蓝牙权限。首次授权需要用户点击确认。

确认实际主控和主板丝印；相同产品名或 HS9118 封装丝印不能证明主控相同。屏幕也可能经过更换。客户端显示主控，刷机工具才根据主板配置选择硬件后端。本期不提供固件和烧录包。

若设备仍运行原厂固件，先完成[首次烧录](flashing.md)。已安装 InkTag 的设备不需要重复完整烧录。

## 2 连接和确认

打开 Web 上位机，点击顶部“连接”，选择与设备对应的蓝牙名称。默认应用名称为 `IKT_平台_后四位`；Recovery 名称带 `_OTA` 后缀。设备显示名称可以与蓝牙名称不同，识别设备时以实际蓝牙身份为准。

在“设置 → 设备设置 → 概览”核对主控和固件版本，再在“设置 → 设备设置 → 显示”核对尺寸、分辨率、颜色和方向。没有读到真实配置时，不要尝试猜测屏幕设置。

## 3 显示内容

在“图片”中导入并处理图片，或在“创作”中使用预置模板。预览方向和颜色后发送到设备，等待最终刷新完成。传输进度到 100% 不表示屏幕已经完成刷新。

支持图片存储的设备可以保存图片并使用轮播。清除图片只删除设备图片；重置设置是另一项操作，请先阅读确认内容。

## 4 更新和帮助

日常更新使用“设置 → 设备设置 → 固件”中的 OTA，详见[更新说明](ota.md)。首次安装、Recovery 升级或无法无线恢复时才需要有线完整烧录。

“设置 → 客户端设置 → 关于”提供项目、Web 上位机、手册链接和入门教程弹窗。遇到问题先保存固件版本、准确板型和错误提示；不要公开密码、激活码或私有定位数据。
