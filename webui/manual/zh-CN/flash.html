首次安装与完整烧录

原厂价签首次安装 InkTag 使用有线烧录。已安装兼容 InkTag 固件的设备，日常升级见 OTA。先核对主控、主板丝印和屏幕。

用 BAT 烧录

  1. 打开 release/firmware 中对应的目标目录，保留工具、full/ 和配置的相对路径。首次安装使用 Full。
  2. 按下方准备好烧录器和软件。Windows 用户双击 tools/flash-zh.bat 使用中文向导，tools/flash.bat 使用英文。命令行用户在目标目录复制安装说明里的对应版型命令。
  3. 向导找到唯一合用的 Full 会自动采用，多份时列出选项，找不到时打开文件选择框。选择主板和屏幕配置，核对烧录范围后再确认。
  4. 确认后默认持续检测，直接烧录的 flash-bin.bat、flash-hex.bat 也默认轮询。按窗口提示取消。轮询只用于初始探测。写入或回读失败后，先保留提示并核对目标状态。

烧录前准备

GR、OM、nRF52811 和 nRF52832 的推荐 BAT 使用 Windows 自带的 PowerShell 5.1／.NET，无需安装 Python。使用 J-Link 的平台统一安装 SEGGER J-Link Software and Documentation Pack 7.88j（Windows x64） 及 USB 驱动。7.88j 是软件版本。 SEGGER 下载页

主控 接口 还需准备
GR5331、GR5513／GR5515 J-Link／SWD Goodix GProgrammer console 2.0.3.0，保留随附的 loader、DLL 和配置
OM6626 J-Link／SWD 已随仓库提供 OM 设备支持文件
nRF52811、nRF52832 J-Link／SWD 上述 J-Link 软件和驱动即可
TLSR8359 CH340／SWS Python 3.11+ 和 CH340 驱动，首次运行 setup.bat 安装串口工具依赖
DA14585 J-Link／SWD Python 3.12+，让 python 命令可用。烧录工具自动校验随包的 SRAM helper

TLSR 在 release/firmware/tlsr8359_hsel/ 中执行以下命令，或双击 setup.bat。命令行带参数调用会返回退出码：

.\tools\setup.bat -Python python

选择烧录器

  • 上侧 J-Link OB 用于 ARM 主控的 SWD 烧录。按主板说明接 SWDIO、SWCLK、GND 及所需电源或复位线。
  • 下侧 CH340 + 1–2 kΩ 电阻 用串口模拟 Telink SWS。速度和稳定性取决于接线和 USB 时序。按接线图连接，使用与主板匹配的信号电平。

两种小板的参考购入价均不到人民币 10 元，不含配件。系统未识别 CH340 串口时，安装沁恒的 Windows 驱动或 macOS 驱动。Telink 的 CH340／SWS 方案可在 macOS 使用，参考 macOS 串口工具说明。nRF 的 DAPLink／SWD 曾在 macOS 验证可行，当前 BAT 流程使用 Windows。

使用预转换的 BIN／HEX

GR、TLSR 和 nRF52832 的 flash-images/ 存放可直接用于烧录工具的镜像及地址表。请选择匹配主板和屏幕的文件。BIN 需要对应的写入地址及地址空间，Intel HEX 自带地址记录。

  • GR 和 TLSR 提供 flash-bin.bat。GR 使用配套初始化物料，TLSR 使用对应 BIN 及同名 JSON。用 BDT 烧 TLSR 时按该板型地址表操作。
  • nRF52832 提供 flash-hex.bat。

完整烧录及初始化可能清理设置和数据。先按板型说明备份，烧录完成后核对回读结果。

为什么这三个平台推荐用 flash.bat

以下三款主控请从 tools/flash.bat 或 tools/flash-zh.bat 进入，选择对应主板配置。

  • OM6626 使用 Full ZIP。BAT 会保留原厂启动区，再按所选主板配置安装 App 和 Recovery。单独的 App／Recovery 分段无法完成这套安装。
  • nRF52811 使用 Full ZIP。内部 Flash、外置设置和 GUI 资源需要分别写入，App 与 GUI 必须配对。BAT 会处理这三部分。需要分开烧录时，可用 generate-hex.bat 生成三份配套 HEX。
  • DA14585 使用 full/ 中的 Full BIN。BAT 按板型准备外置 SPI Flash 写入数据，并跳过原厂区域 0x39000–0x3AFFF。有线写入所用的 SRAM helper 已随包提供，BAT 会自动查找和校验。ota/ 中的 IMG 用于无线更新，无需 SRAM helper。
