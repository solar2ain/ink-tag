InkTag 客户端 / InkTag clients

中文

  • WebUI 1.2.0：画板、图片抖动、屏幕效果预览、天气站和日期牌模板。
  • CLI 0.2.0：设备管理、图片传输、轮播及主机动态页面任务，需要 Python 3.11 或以上版本。
  • 提供静态网页 ZIP、独立 HTML、CLI 源码包、sdist、wheel 和本地服务包。
  • 本期不包含固件、有线烧录包或开发诊断功能；正常设备状态查询仍保留。
  • 自动天气推送需要主机持续在线，启用前请在自己的设备上确认能够正常接收。
  • 部分编译组件的对应源码与许可信息尚未齐备，当前文件暂不作为正式公开发行包提供，详见许可说明。

下载后请对照同版本 SHA256SUMS.txt 检查文件完整性。客户端更新不会自动刷写设备。

English

  • WebUI 1.2.0: editable canvas, dithering, device-effect previews, weather and date-card templates.
  • CLI 0.2.0: device management, image transfer, slideshows and host-page tasks; Python 3.11 or later required.
  • Includes static ZIP, standalone HTML, CLI source ZIP, sdist, wheel and the local-service package.
  • No firmware, wired flashing packages or development diagnostics are included; ordinary device status queries remain available.
  • Scheduled weather delivery requires the host to remain online. Confirm delivery on your device before enabling it.
  • Some compiled-component source and licensing information is still missing. These files are not yet offered as a formal public release; consult the licensing notice.

Check downloads against the same version's SHA256SUMS.txt. Client updates never automatically flash a device.
