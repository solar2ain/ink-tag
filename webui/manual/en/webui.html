InkTag WebUI

Web console

Scanning the device-information QR or opening a link with a ble parameter attempts an exact-name connection to a device already authorized for this origin. If unavailable, a connection dialog appears. Click Choose Bluetooth device to open the browser chooser and confirm the target. First-time Bluetooth permission requires a user gesture; the page cannot silently grant it. Cancellation stops automatic attempts, and normal device-password checks remain in force.

Use the hosted HTTPS site, compiled static files, standalone HTML or local-server package. These packages do not require Node.js at runtime. The browser must support Web Bluetooth; otherwise use the CLI.

Install and open

Open InkTag Web in Chrome or Edge with Web Bluetooth. For local operation, install Python 3.11+, extract InkTag-local-server, enter that directory and run:

# Windows
install.cmd

# Linux / macOS
# macOS: install.command; Linux:
sh install.sh

Open http://127.0.0.1:8787/. Closing the terminal stops the foreground service; restarting retains per-user data, %LOCALAPPDATA%/InkTag on Windows. Keep Apple sessions, identity libraries and credentials private.

For static ZIP, run python -m http.server 8787 --bind 127.0.0.1 inside webui. This provides pages, not the Find backend. Standalone HTML is a single-file option subject to browser secure-context rules. LAN Bluetooth access requires trusted HTTPS, not ordinary LAN HTTP. Do not disable browser security to enable Bluetooth.

Phone and LAN access

Local-only operation does not add a login step. To enable phone access, run this from the local-server package:

python start.py --lan

With the CLI installed, use inktag webui serve --repo . --lan. The service discovers local addresses, prepares HTTPS and displays the browser address and a password for this run. Connect the phone to the same network and sign in as inktag. Trust only the certificate generated by your own computer. The phone browser must trust the certificate for Bluetooth access; some mobile browsers do not support Web Bluetooth at all.

Allow the selected port through the local firewall; do not expose a private-data/Find service directly to the internet. Custom DNS names can use --allowed-host NAME; existing certificates use --tls-cert and --tls-key. Advanced deployments may supply a stable service password using --access-password-stdin. This is separate from device and Apple passwords. Most users do not need these advanced options.

Canvas and weather station

The canvas under Create supports text, image frames, tables, lists, QR codes and brush strokes. Double-click an image frame to select an image and choose fit and dithering options. Device-effect preview simulates the target palette locally; it neither connects nor refreshes a device. Static pages can use browser fonts without installing device font resources.

Weather templates use editable values, icons, trend charts and forecast controls. Export a host task, then use the CLI to bind its target and run the schedule. Closing the browser does not stop the CLI. See Host pages and weather station.

Browser preferences

The local service keeps recently used compiled assets in webui-build-cache/ inside its data directory for 30 days, so an open page can still load its old modules after an update. Only hash-named static files are cached, not accounts, device credentials or Find data. Retry an image-tool loading failure locally; finish any device operation before refreshing the whole page. Clear image removes only the current imported image, without reloading or deleting device pictures.

Settings → Client settings → Preferences selects browser-default, Simplified Chinese or English, and system, light or dark appearance. Selections belong to the current browser origin, not the device. English currently covers navigation, preferences and the tutorial; detailed device text may retain its original language.

Reopen the tutorial under Settings → Client settings → About. Different hosts/ports have separate settings. Clearing site data resets preferences; blocked storage makes changes session-only. Operation progress and waiting indicators remain visible.

NFC and input extensions

Feature Conditions and behavior
Tap to connect (Free) A qualified NFC tag exposes its existing console link to the phone. First Bluetooth use still requires browser permission. Reading a link does not execute a device action.
NFC page switching (Pro) Page changes and supported short commands require Pro, reported hardware support and the existing password protection. NFC image transfer is not yet available.
Buttons and buzzer Unavailable extensions are marked not implemented and cannot be written. Qualified onboard buttons remain available according to actual device capabilities.

Connect and use

Select Connect and the exact Bluetooth name. Wait for identity and settings to load. Connection history shows the Bluetooth name first and the device label below. Recovery is a separate role and may require another browser grant.

The introduction appears on first use and can be reopened under Settings → Client settings → About. Settings groups Overview, Display, Hardware, Interaction, Activation, Firmware, Logs and Tests under Device settings; Preferences and About belong to Client settings and work without a device connection.

Check the panel configuration before sending content. Wait for display completion, not just transfer completion. Read any image-clear confirmation before changing an incompatible panel profile. Password management uses device operations; changing or deleting a password requires fresh verification of the old password.

Settings → Device settings → Activation serves Pro-capable devices. See Pro features and activation for the Apple Find My tracker, more slots, NFC interaction and activation steps.

First picture and stored images

  1. Check Settings → Device settings → Display for the current controller, preset, colors and orientation.
  2. Import a picture and adjust cropping, rotation and colors using the device preview.
  3. Display it directly or save in an available slot.
  4. Wait for transfer and physical refresh. Flashing is usually part of the waveform; 100% transfer is not refresh completion.

Create offers templates with previews. The introductory tutorial includes screenshots with boxes/arrows and can be reopened in About. Resources lists actual slot IDs, display/download/delete actions and slideshow controls. IDs can have gaps. Slideshow runs autonomously after disconnecting; stop explicitly when finished.

See device/panel capacity. Changing geometry/colors may invalidate stored pictures. Download important content first and read the explicit image-clear confirmation; saving a setting and deleting pictures are different operations.

Settings → Device settings → Firmware handles OTA. Package validation alone is not OTA success: device validation and a verified return to the application must follow. For errors or an unknown result, read the message and logs before taking another action. Diagnostics show unavailable values as --; MCU and panel temperatures are distinct. Keep private Find data and credentials out of shared reports.
