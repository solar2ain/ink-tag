The existing Chinese glyph-supplementation catalog contains two Bold faces:
WQY9: 12-pixel / 9-point Bold; WQY12: 16-pixel / 12-point Bold.
Font family: WenQuanYi Bitmap Song; foundry: WenQuanYi;
font metadata version: 000.990 (WenQuanYi release 0.9.9).
Each catalog face contains 27,535 codepoints, from U+3000 through U+9FA5.
These are font data, not a new font family or a grant for InkTag-owned code.

原有中文补字目录含 WQY9 与 WQY12 两套粗体，每套 27,535 个字形。
字体许可独立于 WebUI、U8g2 代码及其他组件的许可。
