# Third-party components

InkTag's Goodix host tools use GPL-3.0. See [Goodix tool license](../Goodix-tools-GPL-3.0.txt).
The adapted CLI components retain their license and notices in
`tools/internal/runtime/cli/`. The default native-font template contains
font data under its original terms.

Install the Goodix GProgrammer and SEGGER J-Link tools from their vendors.
The Windows flashing and image generation BATs use PowerShell 5.1 and .NET.
