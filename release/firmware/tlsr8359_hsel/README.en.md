# Flash TLSR8359 HSEL

Match the PCB marking in the [flashing guide](INSTALL.en.md). Run [setup.bat](tools/setup.bat) once, then open [flash.bat](tools/flash.bat). You need Python 3.11+, a CH340 driver, and SWS wiring.

[tools/configs](tools/configs/) holds the board presets. [flash-images](flash-images/) holds the converted BIN images and their matching address maps. The bundle includes the format code and its [license](../LICENSE).
