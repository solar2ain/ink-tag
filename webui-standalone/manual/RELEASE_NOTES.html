选择下载内容

  • 在线使用：直接打开 WebUI。电脑使用 Chrome／Edge，iPhone／iPad 推荐 Bluefy，Android 使用 Chrome。
  • 本地客户端：CLI ZIP 包含本地 WebUI 和 Find 后台，需要 Python 3.11 或更新版本。完整解压后安装 CLI，再启动本地 WebUI，步骤见包内 README。
  • 离线网页：完整解压 standalone ZIP，打开 InkTag-WebUI.html，保留旁边的资源目录。
  • 自行托管：选择静态 WebUI ZIP。
  • 已安装 InkTag：选择与实际主控、主板匹配的 OTA 包，通过 WebUI 或 CLI 升级。
  • 首次安装或有线恢复：选择完整固件，阅读对应工具目录的中英文 README，并显式传入固件文件。

烧录工具以明文目录独立提供，不包含或自动选择固件。DA14585 的公开便携工具目前只支持探测和离线预检，实际完整烧录尚未开放。请按各目录说明确认可用操作与依赖，不要仅按屏幕尺寸选择固件。

下载后核对 SHA256SUMS.txt。客户端更新不会自动刷写设备；传输完成后仍需等待设备回连与验身。使用前请阅读许可说明和各组件声明，尚未齐备的来源／对应源码信息仍在说明中列明。

Illustrated manual · Open WebUI · Local client guide

  • The CLI ZIP includes local WebUI and the Find backend; Python 3.11 or newer is required. Follow its README to install the CLI and start local WebUI.
  • For offline browser use, extract the standalone ZIP and open InkTag-WebUI.html, keeping its resources alongside it. A separate static WebUI ZIP is available for hosting.
  • Existing InkTag installations use an OTA package matching the actual controller and board. First installation or wired recovery requires complete firmware and the matching programmer/configuration.
  • Programmer tools are plaintext directories, independent of firmware downloads. DA14585 portable tools currently support probing and offline validation only; actual complete flashing is not enabled. Follow each bilingual README for available operations and dependencies.

Use Chrome/Edge on desktop, Bluefy on iPhone/iPad, and Chrome on Android. Verify downloads with SHA256SUMS.txt. Client updates do not automatically flash devices, and transfer completion is not final App attestation.
