# 公开工具目录

- `findmy/`：本地客户端和 Find 查询服务的安装、认证及网页资源；普通本地使用需要，不能单独删除。
- `nfc/`：PN532／PCR532 的 NFC 读写、文本命令及传图入口。
- `platforms/<厂商>/<主控>/programmer/`：维护各平台烧录脚本和配套板型配置。
- `sdk/`：准备厂商 SDK、生成资源及构建固件的共用脚本。
- 根目录 Python 脚本：手册生成、发布清单、附件校验和 Pages 检查。正式发布入口由维护库管理。
- `tests/`：这些公开维护脚本的纯离线回归测试，不含设备开发诊断。

用户烧录时，使用 `release/firmware/<主控_主板>/` 内与固件配套的工具。 [完整烧录说明](../docs/zh-CN/flash.md)
