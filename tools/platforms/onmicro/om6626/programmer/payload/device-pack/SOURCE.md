# OM6626 J-Link device support files

Source: [jtcom/OM6626 — tools/plugins/jlink](https://gitee.com/jtcom/OM6626/tree/c34a8ef327572bcf22aa93dfd30b970b47bc3c5e/tools/plugins/jlink) at commit `c34a8ef327572bcf22aa93dfd30b970b47bc3c5e`.

This directory contains the vendor's OM6626 device description and two J-Link flash loaders. The ELF files match the upstream bytes. The XML uses the pinned Windows CRLF byte form. File hashes are recorded in the [dependency list](../../records/dependencies.json).
