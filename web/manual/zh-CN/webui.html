Web 上位机使用手册

InkTag Web 有三种运行模式：Python 本地服务、GitHub Pages 等 HTTPS 静态站点，以及单文件 standalone HTML。三者运行时都不依赖 Node.js。推荐使用最新版 Chrome 或 Edge；蓝牙访问需要 HTTPS、localhost 或浏览器明确允许的本地文件环境。

连接设备

  1. 给价签正常上电，确保它没有停留在首次烧录或 Recovery 的接线状态。
  2. 点击“连接设备”，在浏览器设备选择器中选择名称与标签后四位相符的 InkTag 设备。
  3. 等待页面显示主板 ID、固件版本、能力和屏幕 profile。主板无法识别时不要发送屏幕或 OTA 命令。
  4. 重新点击“连接设备”可以改连另一台设备。页面会根据设备能力隐藏不支持的功能。

浏览器记住的是授权过的蓝牙设备，但操作系统仍可能要求再次选择。普通应用广播与 _OTA/Recovery 广播属于同一台设备的不同运行角色；升级期间按页面提示完成授权。

屏幕、日历与时钟

  • 首次使用先核对屏幕尺寸、颜色、控制器和方向；保存后重连确认配置仍然一致。
  • 清屏、日历、时钟和传图是互斥操作。页面显示刷新中时不要断电；需要改做其他操作时先使用停止功能，等待设备确认停止。
  • BUSY 完成表示控制器报告刷新结束，不只代表 BLE 数据发完。三色、四色和低温面板可能明显更慢。
  • 屏幕出现镜像、裁切、彩条、整屏红/黑或 BUSY 超时时，停止操作并重新核对 profile，不要连续刷新。

图片处理与图槽

载入图片后先选择适合墨水屏的裁剪区域，再预览黑、白和彩色平面。页面会按设备回传的物理分辨率生成最终数据；旋转画布只改变编辑方向，不应要求用户在发送前手工“转回去”。不带灰度能力的屏幕不会显示灰度加深选项。

支持图槽的设备可以保存多张设备就绪图片并设置轮播。切换到分辨率不同的屏幕 profile 时，已有图片可能不再兼容；先导出或确认清理提示，再写入新图片。

OTA

页面底部 OTA 区域只在已识别设备支持升级时启用。必须选择与主板 ID 完全一致的 ota.zip，等待上传、校验、切换运行角色、重连和版本确认全部完成。详细恢复方法见 OTA 升级。

隐私与故障排查

纯静态 WebUI 的图片处理和蓝牙通信发生在浏览器本机。只有用户主动启用的外部功能才可能访问网络；部署者应阅读页面中的对应隐私提示。

  • 找不到设备：确认系统蓝牙、位置/扫描权限、设备供电和名称过滤；关闭占用设备的其他网页或应用。
  • GATT 断开：等待屏幕刷新结束，重新上电后再连接；不要同时打开多个控制页面。
  • 假期数据失败：确认通过 HTTP/HTTPS 访问且静态资源完整；失败不应阻止基础日历切换。
  • 页面版本过期：刷新站点缓存，或重新下载同一 Release 的独立 HTML。
  • 操作结果异常：保存页面日志、主板 ID、profile、固件版本和复现步骤，但不要公开设备密钥或原厂固件。
