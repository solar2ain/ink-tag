OTA 升级

OTA 包只能用于同一个主板 ID。不要解压或修改 ZIP，也不要把完整固件当作 OTA 包上传。

  1. 打开 InkTag Web 并连接设备。
  2. 在页面底部的 OTA 区域确认识别出的主板与当前版本。
  3. 选择同一版本发布中的 InkTag-<主板>-v<版本>-ota.zip。
  4. 等待上传、校验、切换和设备重新广播完成。
  5. 重连后确认固件版本、时间、屏幕 profile 和已保存设置。

如果升级中断，不要连续重复操作。先等待设备正常广播或 _OTA 广播，再按该平台的恢复说明处理。正式版本必须通过正常升级、断电中断、损坏包拒绝和回退测试。

本次延期的 Nordic Secure DFU 和 Dialog SUOTA 传输仍可被 CLI 识别，但没有 0.2 候选固件附件。

升级完成的判定

进度到 100% 只说明主机发送完成。必须继续等待设备端校验、切换、重启和应用重新广播，并重新读取：准确主板 ID、新版本、时间、屏幕 profile、蓝牙名称和持久化设置。图槽设备还要抽查图片目录和轮播配置没有被升级覆盖。

以下任一情况都应判为失败：包与主板不符仍可发送、签名/摘要错误仍被接受、应用未重新广播、版本未变化、配置丢失，或中断后既没有正常广播也没有 _OTA/Recovery 广播。此时停止重复上传，记录日志和包 SHA-256，并使用完整烧录说明中的恢复路径。
